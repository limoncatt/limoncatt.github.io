# Material3Custom

My take on material 3 expressive

## Development

The site makes no requests to any CDN or third-party server at runtime. Two things are generated and committed:

- `tokens.css`: colour roles (dark and light), spring easings and morphable shapes, generated by `scripts/generate-tokens.mjs`. To change the look, edit the seed colour, spring values or shapes at the top of that file.
- `vendor/material.js`: the Material Web bundle (just the ripple), built from `src/material.js`.

After changing either source, or updating a dependency:

```
npm install
npm run build
```

Then commit the regenerated files. GitHub Pages serves the repo as-is, so no other build step is needed.

Scroll effects use CSS scroll-driven animations (Chrome, Edge, Safari 26+). Other browsers get the same page with simpler entrance animations, and `prefers-reduced-motion` turns the motion off entirely.
